매치3 퍼즐의 핵심은 **같은 타일이 가로 또는 세로로 3개 이상 이어졌는지** 판정하는 것입니다.

## 보드 표현

보드는 `board[y][x]`에 타일 종류(정수)를 저장하고, 빈칸은 `-1`로 둡니다.

```gdscript
const BOARD_W := 8
const BOARD_H := 8

var board: Array = []  # board[y][x] = 타일 종류, 빈칸은 -1
```

## 매칭 판정

한 줄을 훑으면서 같은 값이 이어진 길이(`run`)를 세고, 연속이 끊기는 순간 길이가 3 이상이면 해당 칸들을 기록합니다.
같은 칸이 가로·세로 양쪽에 걸릴 수 있으므로 `Dictionary`를 집합처럼 사용해 중복을 제거합니다.

```gdscript
func find_matches() -> Array[Vector2i]:
	var matched := {}

	# 가로 검사
	for y in BOARD_H:
		var run := 1
		for x in range(1, BOARD_W + 1):
			if x < BOARD_W and board[y][x] != -1 and board[y][x] == board[y][x - 1]:
				run += 1
			else:
				if run >= 3:
					for i in run:
						matched[Vector2i(x - 1 - i, y)] = true
				run = 1

	# 세로 검사
	for x in BOARD_W:
		var run := 1
		for y in range(1, BOARD_H + 1):
			if y < BOARD_H and board[y][x] != -1 and board[y][x] == board[y - 1][x]:
				run += 1
			else:
				if run >= 3:
					for i in run:
						matched[Vector2i(x, y - 1 - i)] = true
				run = 1

	var result: Array[Vector2i] = []
	result.assign(matched.keys())
	return result
```

### 포인트

- 루프를 `BOARD_W + 1`까지 돌려 **줄 끝에서 끝나는 연속**도 같은 분기에서 처리합니다.
- 빈칸(`-1`)끼리는 매칭으로 보지 않습니다.
- 반환값은 제거할 칸 좌표 목록이므로, 이후 낙하·리필 단계에 그대로 넘길 수 있습니다.
